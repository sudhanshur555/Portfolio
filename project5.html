Swift Pico Drone Navigation & Inventory Validation (e-Yantra)

Autonomous drone navigation in Gazebo using ROS 2, OpenCV, and custom action servers for inventory validation.

Demo Video

Project demonstration video showing the drone navigating the simulated warehouse environment.

Project Overview

This project involves autonomous navigation and inventory validation using the Swift Pico Drone in a simulated warehouse environment built with Gazebo. The drone utilizes ROS2 for real-time communication and control, enabling precise movement, collision avoidance, and package identification. This work extends across multiple tasks involving 2D mapping, path planning, and validation of packages at known locations.

View Project on GitHub

Technical Deep Dive

Key Features

  • 2D Mapping: Uses Aruco markers to generate a 2D bitmap of the warehouse for path planning.
  • Autonomous Navigation: Custom ROS 2 action server for waypoint navigation with real-time error checking (±0.6m).
  • Inventory Validation: Conducts package identification with stable hovering for 3 seconds at each location.
  • ROS 2 Comms: Utilizes custom services and action clients/servers for managing waypoints and path planning.

Task Workflow

  • Task 2A: Waypoint navigation in Gazebo simulation.
  • Task 2B: Path planning using Aruco-based 2D mapping.
  • Task 2C: Inventory validation with package detection and hovering at predefined points.

Technical Highlights

  • ROS 2 Communication: Custom service and action interfaces for waypoint retrieval, path planning, and navigation feedback.
  • Gazebo Integration: Simulates warehouse environment and Swift Pico model for realistic testing.
  • Collision and Error Checking: Monitors potential collisions and height violations throughout navigation.
  • Results: The drone successfully navigates, hovers at each package location, and maintains stable flight within defined error margins.

Prerequisites & Setup

The project requires ROS 2, Python 3.8+, Gazebo, OpenCV, and WhyCon for height stabilization.

# 1. Clone the repository
git clone https://github.com/sudhanshur555/Eyantra_Warehouse-Drone.git
cd Eyantra_Warehouse-Drone

# 2. Install Dependencies
sudo apt install ros-<distro>-gazebo-ros-pkgs python3-opencv

# 3. Set Up Environment
export GZ_SIM_RESOURCE_PATH="$HOME/Eyantra_Warehouse-Drone/models"

# 4. Build the Workspace
colcon build
source install/setup.bash

Usage (Simulation Launch)

In separate terminals, start the simulation, service, server, and client nodes:

# Terminal 1: Launch Simulation
ros2 launch swift_pico task_2c.launch.py

# Terminal 2: Warehouse Service
ros2 run swift_pico warehouse_service.py

# Terminal 3: Action Server
ros2 run swift_pico pico_server_2c.py

# Terminal 4: Action Client
ros2 run swift_pico pico_client_2c.py
