Indoor Navigation Bot (MyBot)

A differential drive mobile robot built for autonomous navigation and SLAM using ROS 2.

Demo Video

Here you can see the robot mapping an environment in real-time and then autonomously navigating to a goal.

Project Overview

This repository contains the complete ROS 2 workspace for MyBot, a differential drive mobile robot built for autonomous navigation and SLAM.

View Project on GitHub

Key Features

  • Full Robot Bringup: Launch files to bring the robot hardware, sensors, and software stack online.
  • SLAM: Real-time map building using `slam_toolbox`.
  • Localization: EKF-based sensor fusion for accurate odometry using `robot_localization`.
  • Web-Based Tuning: The motor controller (ESP32) hosts a webpage for real-time PID tuning without re-flashing.
  • Navigation: Full autonomous navigation with the ROS 2 Nav2 stack.
  • Simulation: Complete Gazebo simulation model and launch files for testing and development.

Technology Stack

Hardware

  • Chassis: Custom 3D Printed
  • Compute (On-board): Raspberry Pi 4 (4GB)
  • Microcontroller: ESP32 (Motor controller & encoder)
  • Motors: DC Motors with Encoders
  • Motor Driver: L298N
  • Sensors (IMU): MPU-6050 / BNO085
  • Sensors (LiDAR): RPLidar A1
  • Power: 12V LiPo Battery + 5V Buck Converter

Software

  • OS: Ubuntu 22.04
  • ROS 2: ROS 2 Humble Hawksbill
  • Primary Languages: Python and C++
  • Firmware: ESP32 w/ WiFi web server for on-the-fly PID tuning.
  • Key ROS 2 Packages:
    • slam_toolbox
    • robot_localization (EKF)
    • nav2_stack
    • ros2_control

ROS 2 Workspace Structure

This workspace is organized into several custom ROS 2 packages:

Package Description
mybot_bringupContains all top-level launch files for starting the robot.
mybot_descriptionHolds the robot's URDF (Unified Robot Description Format) files.
mybot_firmwareCode for the microcontroller and the `ros2_control` hardware interface.
mybot_controller`ros2_control` controller configurations and custom controller code.
mybot_localizationEKF configuration files for `robot_localization`.
mybot_mappingConfiguration and launch files for `slam_toolbox`.
mybot_planningNav2 stack configuration files (planners, controllers, BT).
mybot_msgsCustom ROS 2 message and service definitions.
mybot_utilsContains utility scripts and nodes used by other packages.
mybot_calibrationScripts for sensor calibration (e.g., IMU, camera).
mybot_motionHigh-level motion logic (e.g., "go to goal").

Installation & Setup

These are the steps to clone and build the project.

1. Prerequisites

  • A computer with Ubuntu 22.04 installed.
  • ROS 2 Humble (Desktop Install).
  • Git and colcon.

2. Clone & Build

# 1. Create a new ROS 2 workspace
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src

# 2. Clone this repository
git clone https://github.com/sudhanshur555/Indoor_navigation_bot.git

# 3. Go back to the workspace root
cd ~/ros2_ws

# 4. Install dependencies from ROS packages
rosdep install --from-paths src -y -i

# 5. Build the workspace
colcon build

# 6. Source the workspace
source install/setup.bash

# 7. Launch the project on real hardware
ros2 launch my_bot_bringup real_robot.launch.py use_slam:=true use_sim_time:=false
